# Collector Agent (수집가)

## 역할
HWP 도정보고 파일을 파싱하고, 규칙에 따라 행사를 필터링 & 정제.

## 입력
```python
hwp_file: str          # HWP 파일 경로
target_month: int      # 보고 대상 월 (예: 5 → 6월호 생성)
```

## 출력
```python
Event[]:  [
  {
    day: int,          # 1~31
    date: str,         # "6. 1"
    time: str,         # "10:00"
    title: str,        # "역대 도지사 간담회"
    place: str,        # "한국프레스센터 19층"
    subtitle: "",
    body: "",
    priority: 3
  },
  ...
]
```

## 절차

### 1️⃣ HWP 파싱
- OleFile로 BodyText/Section0 스트림 읽기
- zlib 압축 해제
- HWPTAG_PARA_TEXT (tag=67) 필터링
- UTF-16-LE 디코딩 → 한글 단락 추출

### 2️⃣ 월별 섹션 식별
- 헤더: `"2026년 {month}월 평안남도 주요일정"`
- 시작 인덱스 ~ 다음 달 헤더까지 추출

### 3️⃣ 캘린더 구조 파싱
```
SUN(일) / MON(월) / ...   ← 요일 헤더 (SKIP)
1 / 2 / 3 / ...          ← 날짜
HH:MM                    ← 시간
행사명 (줄여서)
(장소)
```

### 4️⃣ 필터링 (MAENGHO_SPEC.md §4)

**SKIP_EXACT**: 완전 일치
```python
"SUN(일)", "MON(월)", ..., "SAT(토)"
"노동절", "부처님 오신날", "대체휴일"
"지사님 대체휴무", "지사님 연가"
```

**SKIP_PARTIAL**: 포함 시 제외
```python
# 휴무·휴가
["연가", "대체휴무", "대체 휴무", "건강검진", "안과진료"]

# 내부 행정
["도 직원회의", "직원회의"]

# 경조사
["결혼", "돌잔치", "장례", "빈소", "부고", "영결식"]

# 기타
["주요일정", "氠瑢"]
```

### 5️⃣ 중복 제거
- 기준: (날짜, 제목 앞 6자)
- 같은 조합 첫 번째만 유지

### 6️⃣ 개수 제한
- "위원회 간담회": 1건만 허용
- 나머지는 제한 없음

### 7️⃣ 정렬
- 날짜 순서 (day ASC)
- 같은 날 내에서는 시간 순 (time ASC)

## 에러 처리

| 상황 | 동작 |
|------|------|
| 파일 미존재 | ❌ 종료 + 에러 메시지 |
| 월 헤더 미발견 | ❌ 종료 + 에러 메시지 |
| OleFile 손상 | ❌ 종료 + 에러 메시지 |
| 행사 0건 | ❌ 종료 + 경고 |

## 성공 기준
- ✅ 단락 추출 N개
- ✅ 행사 M개 필터링
- ✅ 정렬 완료
- ✅ raw_events[] 반환
